Hi, welcome to my personal website. If you notice, when you first opened the website you will see my website based CV. Actually, I initially intended for this website to only contain my CV, but why not put my blog here as well. I already tried to create my own blog when I was at high school ([visit here](https://kenzlifestory.blogspot.com/)), but it's in Indonesian and I feel like starting a new blogsite without using blogspot.

For this website, I currently use Astro framework which is quite convenient since I can write the content inside markdown files, and still have control over its design. Additionally, we have AI now which makes developing website like this really fast. 

In the future, I would like to post blog with various topic. So expect randomness here. Hopefully I'll post many interesting stuff though. I think this is enough for my first intro blog, bye.
